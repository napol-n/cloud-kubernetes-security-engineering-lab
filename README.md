# Cloud & Kubernetes Security Engineering Lab

Hands-on security engineering project focused on container security, Kubernetes hardening, Infrastructure as Code, CI/CD security, policy enforcement, vulnerability management, and remediation validation.

## Project Goals

- Build and assess containerized workloads
- Deploy workloads to local Kubernetes
- Identify container and Kubernetes security misconfigurations
- Implement least-privilege security controls
- Scan containers and Infrastructure as Code
- Build security checks into CI/CD
- Implement Policy as Code
- Document findings, remediation, and retesting with reproducible evidence
